# Translation policy

English is canonical for code, schemas, architecture, and operational contracts.

`README.fr.md` preserves the product intent and entry point in French. It must be updated when the English README changes materially.

Do not translate code identifiers, API paths, configuration keys, model IDs, file paths, commands, or exact error codes. Do not weaken safety, privacy, licence, rollback, or resource warnings. A translation may clarify language but cannot create a second product authority.
