# ADR-0007 — Apache License 2.0 for original work

- Status: Accepted
- Date: 2026-08-27
- Related gates: G-09, G-11

Original code/docs use Apache-2.0 for permissive reuse with explicit patent grant. Downloaded models/runtimes/datasets/libraries retain independent licences. Registry/installer exposes them and prevents bundling assumptions. Restrictive or unclear terms may block routes or redistribution.
