# G-08 audio transcription - 2026-08-28

Lot authorised by explicit `GO G-08`. Reuses the G-05 job core. No permanent
runtime service, no live UI wiring, no Hermes `config.yaml` mutation.

## Default

`audio.transcribe@1` / profile `balanced` / whisper.cpp `base`.
`fast` is tiny. `small` measured, not default. Large not selected.

## Behaviour

- WAV/MP3/FLAC/OGG via ffmpeg decode to 16 kHz mono
- energy VAD; no-speech is unsupported
- 30 s chunks, 15 min ceiling
- timestamps, language hint, cancellation via job core
- `/v1/audio/transcriptions` adapter
- metadata-only logs
