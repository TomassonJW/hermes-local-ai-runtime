# G-09 packaging and safe installation - 2026-08-28

Lot authorised by explicit `GO G-09`. Reuses no permanent service. The
installer writes a prefix, never enables systemd, never downloads models,
never mutates Proxmox, never changes Hermes `config.yaml`.

## Matrix

`packaging/matrix.yaml`: Ubuntu 24.04 x86_64 supported. Other OS/arch
unsupported until G-11.

## Layout

prefix/etc, prefix/lib, prefix/share/notices, prefix/share/sbom,
prefix/share/systemd, prefix/var/lib, prefix/var/models, prefix/var/backups.

Listen host is 127.0.0.1. Model-store quota default 30 GiB. User unit is
copied into the prefix only.

## Proof

`python3 scripts/g09_eval.py` (2026-08-28): loopback, notices, SBOM, unit
shipped, user unit not enabled, toy blob registered by hash, backup then
upgrade, prefix removed in finally.

## Rollback

`python3 -m installkit backup --prefix PATH`
`python3 -m installkit rollback --prefix PATH`
`python3 -m installkit uninstall --prefix PATH --purge`
